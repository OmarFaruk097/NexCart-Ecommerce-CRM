# NexCart_E-commerce

A modern, responsive e-commerce application with a built-in CRM dashboard for managing products, users, orders, and support tickets.

## Tech Stack
- **Frontend**: React, Vite
- **Backend**: Node.js, Express
- **Database**: MySQL

## Features
- E-commerce Storefront (Product Catalog, Cart, Checkout, User Accounts)
- CRM Dashboard (Admin Orders, User Management, Inventory, Support System)
